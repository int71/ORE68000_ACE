・概要
	文字コード指定すると該当文字のビットマップデータが返される。
	ビット深度は1と4に対応。

・I/O仕様
	+-----------+---+---+---+---+---+---+---+---+---+---+---+---+---+---+---+---+-----------------------------------------------------------------------------------+
	|           |F  |E  |D  |C  |B  |A  |9  |8  |7  |6  |5  |4  |3  |2  |1  |0  |                                                                                   |
	+-----------+---+---+---+---+---+---+---+---+---+---+---+---+---+---+---+---+-----------------------------------------------------------------------------------+
	|Select     |ファミリ番号   |サイズ |深度   |***************************|PT |ファミリ番号/フォントファミリ識別番号(現状「0」固定)                               |
	|(R/W)      |               |       |       |                           |   |サイズ/00:縦8ドット 01:縦16ドット 10:未定義 11:未定義                              |
	|           |               |       |       |                           |   |深度/00:1ビット 01:4ビット 10:未定義 11:未定義                                     |
	|           |               |       |       |                           |   |PT/0:半角(縦横2:1)ピッチ 1:全角(縦横1:1)ピッチ                                     |
	|           |               |       |       |                           |   |※縦16ドット、深度4ビット指定で「0」であれば1ライン「4バイト」、「1」であれば「8バ |
	|           |               |       |       |                           |   |  イト」となる。                                                                   |
	+-----------+---+---+---+---+---+---+---+---+---+---+---+---+---+---+---+---+-----------------------------------------------------------------------------------+
	|Data       |データ                                                         |データ/書き込み時:「SJIS文字コード」の指定                                         |
	|(R/W)      |                                                               |       読み取り時:「ビットマップデータ」の読み取り(オートインクリメント)           |
	|           |                                                               |※「Select」で指定した「アドレス」が有効範囲外の場合、書き込み時は何も起こらず、読 |
	|           |                                                               |  み取り時は「0」が返される。                                                      |
	|           |                                                               |※深度1ビット指定であると、横幅16ドット未満であっても返されるのは1ライン分、上位ビ |
	|           |                                                               |  ットに格納される。                                                               |
	+-----------+---+---+---+---+---+---+---+---+---+---+---+---+---+---+---+---+-----------------------------------------------------------------------------------+
